Colors — Alert family & interactive states（dark）

ADR-028 § Rollout gate 1 のスライス1（18色）。左が light、右がそのダーク対。 比率は各値がその文脈で乗る面に対する WCAG コントラスト比。 正典は design-system.md §2.9、このカードはその視覚ミラー （ds/README.md のレイヤリング）。設計時はサインオフ面として値の確定に 先行したが、確定後は §2.9 が上位 — 値が食い違ったら §2.9 が正しい。 アプリは UIUserInterfaceStyle = Light で固定されているため、 この配色が実機に出るのは gate 1〜5 がすべて閉じてから。

§2.6 Alert Family — base（アイコン・強調文字）

info #7B8FA8 → #97ABC47.2:1 on --night-bg
success #7A9270 → #95B1897.2:1 on --night-bg
warning #C7A566 → #D4B67E8.7:1 on --night-bg
danger #B57870 → #CE97906.9:1 on --night-bg

warning が今も少し明るいのは、琥珀が黄系で輝度が高いため。ただし 輝度の順位を保存すると知覚重みの順位は反転するので、そこは追わない — light では warning は 4 色中最も控えめ（地に対し 2.23:1、他は 3.18〜3.42）なのに、輝度を忠実に写すと dark では最も強い色になる。 当初案 #DBBF8A は 9.58:1 でその反転が最大だった。#D4B67E で 8.74:1 まで下げ、 他の 3 色（6.85〜7.24:1）との差を縮めている。完全に帯へ揃えないのは、 琥珀は明るいというプラットフォーム上の直観と、注意状態としての識別性を残すため。

§2.6 Alert Family — Soft（背景）と Ink（その上の文字）

infoSoft #E8EDF2 → #252D37—
infoInk #4A5A6F → #B3C5DB7.9:1 on Soft
successSoft #E5ECDF → #2A3725—
successInk #4D5F44 → #BFDBB38.4:1 on Soft
warningSoft #F2EAD3 → #383124—
warningInk #6F5C2D → #E0CEAE8.3:1 on Soft
dangerSoft #EDD9D4 → #382624—
dangerInk #6F4540 → #E0B4AE7.7:1 on Soft

Soft と Ink は役割が反転する。light の「淡い地 + 濃い字」が、 dark では「暗い地 + 淡い字」になる。delta をそのまま Soft に当てると暗面の上に 眩しい淡色カードが出て §1 に反するので、ここだけは変換式を使わない。 4 つの Soft は --night-bubble に対し 1.02〜1.08、地に対し 1.19〜1.35 で、 色相だけが温度を伝える。Ink は delta ではなく目標コントラストで配置 している（L=78% → 実測 7.7〜8.4:1）。
--night-success-soft が --night-whisper-bubble（#2F3626）と ほぼ同値（1.003）なのは既存関係の忠実な写像で、欠陥ではない — light 側でも --success-soft と --whisper-bubble は 1.026 でほぼ同値。 トーストと密談バブルは文脈が重ならないので、これを「直さない」こと。

§2.6 実際のトースト（dark）

info — 新しいデモが届きました
success — ダウンロードが終わりました
warning — ダウンロードが一時停止されました
danger — 会話を削除しますか？

運用ルールは light と同じ。Cancel は赤くせず --night-ink-2 のまま、danger は破壊確認のプライマリと実破壊状態のみ。

§2.7 Interactive States — moss を night-moss に載せ替え、alpha を約1.33倍

resting hover .06 → .08 pressed .12 → .16 selected .18 → .24
focus ring #8A9A6C → #A8B888 disabled #605F54 / #222420

alpha を上げるのは、明るい moss を 6% で暗面に重ねてもほぼ判別できないため。 focusRing は light 側が --moss と同 hex を別トークンとして持つ設計なので、 dark でも --night-moss と同 hex を別名で持つ。
disabled 地は --night-bubble より沈める。dark では 「明るい＝浮く」が既に hover / selected の意味なので、無効面を持ち上げると衝突する。 #222420 はカード面に対し 1.151・地に対し 1.086 で、light の #ECE7DA が 白カード 1.235 / 地 1.183 でどちらの面でも見えるのと同じ性質を保つ （当初案 #2A2B26 はカード面に対し 1.049 でカード上では消えていた）。 文字とのコントラストは light の 1.75:1 に対し dark 2.43:1 — どちらも WCAG 1.4.3 の非活性除外に乗る意図的な sub-AA で、あえて読みやすくしていない。

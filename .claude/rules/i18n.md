# i18n Rules — callsite form

Callsite conventions for every layer. UI traps: `i18n-ui.md`; catalog: `i18n-catalog.md`.

## Format-string pattern

Use `String(format: String(localized: "Round %lld / %lld"), current, total)` — explicit
placeholders, **`%lld` for `Int`, `%@` for `String`**. A mismatch is no compile error;
`String(format:)` renders garbage at runtime. Args go in source order; the catalog holds the
positional `%1$@` / `%2$lld` form for translator reordering (`i18n-catalog.md` § "xcstringstool
sync output"). See `GameHeader.swift`.

**Form B cannot pluralize** — the count is substituted *after* the lookup, so `"%lld records"`
ships "1 records" for every count. The sanctioned plural is `Text`-only: hoist to a View, per
`i18n-ui.md` § "Plurals — the sanctioned exception to Form B".

## Form A is a runtime hazard at user-facing callsites

SwiftLint's `form_a_localized_interpolation` blocks `String(localized: "…\(x)…")` in app source.
The SwiftUI sibling — a `LocalizedStringKey` label with `\(…)` — is **not** caught (`i18n-ui.md`
§ "SwiftUI convenience-init label trap").

## Audit planning — three checks before drafting a Tier 2 wrap PR

Against a Tier 2 candidate list (`scripts/check_i18n_potential_keys.py`, unwired from CI). An
`.accessibilityLabel(...)` target goes through `i18n-ui.md` § "Audit triage" first:

1. Grep the catalog for the literal first: xcstringstool dedupes by string, so an existing key
   means **zero** new entries and no new `ja`.
2. **Does the wrap canonicalize a structural bug?** A literal may hardcode what should be
   data-derived (a model size, a count, a unit); wrapping it verbatim freezes that bug into
   the catalog **as the translator source of truth**, and the later fix then costs a Swift edit, a
   catalog rename, and every `ja` update. Parameterize first, or skip.
3. The audit is stateless and re-flags every run, so register a deliberate deferral in
   `docs/i18n/leak-detection.md` § "Explicitly-deferred or permanent carve-outs"; an inline
   `// TODO` is invisible next session.

羊の識別は 色相が担う — light の 4 体は L 82–87% に固まっていて、body 同士のコントラストは 1.03–1.14 しかない。だから「暗くする」変換は明度ではなく色相と絶対彩度を守る必要がある。地に対する比は結果であって目標ではない。設計したのは 7.0–8.0:1 の窓で、下限は Dave の内部コントラスト、上限はブランドアクセント（nightMoss 8.00:1）を追い越さないこと。4 体はこの窓を端から端まで張っている（Alice 7.99 / Dave 7.02）。ΔE2000 は 6 ペア中 4 つが light 以上、下がる 2 つも 98% 台 — 床を規定するのは Alice/Carol の 98.1%、絶対値が最も近いのは Bob/Dave（ΔE 6.10）で 98.6%

§2.7 の wash とは逆向きに動く。wash は「暗い面に載る薄い色」なので dark で alpha を上げた。highlight は「面の上に置く光の反射」で、面が暗くなった分だけ同じ alpha が強い段差になる — だから下げる。仕事が違うので向きも逆になる

床が天井の鏡。スライス2 は「dark の地は light にない天井を持つ」と記録した。ここは床で同じことが起きる — light は near-white の地に対して 20:1 の下向きの余白があるので body の 5.95 倍暗い horn を置けるが、night の地はそれ自体が床なので、body を下げた瞬間 Dave の horn は地より暗くなる。だから eye ÷ face だけは保存できず圧縮する（Dave 2.45 → 1.93）

継承しなかった 3 つの hex 一致。スライス2 では一致を忠実に引き継ぐのが 2 回とも正解だったが、ここでは 3 つとも切る

avatarEyelight は ink と同値 #2D2E26／継承なら nightInk #E8E5D8 → 切る。継承すると目が白くなる。目は本文テキストではなく顔の造作
avatarFaceBoblight は moss と同値 #8A9A6C／継承なら nightMoss #A8B888 → 切る。nightMoss は Bob の dark body #ABB29A より明るい — 顔が体より明るくなって反転する
avatarNoselight は mossInk と同値 #3D4030／継承なら スライス4 で決まる値 → 切る。前方依存を作らない。鼻は顔の上の印、mossInk は淡い地の上の文字
